# Reglas del Proyecto (EB-Web-Oficial)

1. **Idioma**: El lenguaje principal del código, comentarios e interacciones debe ser **Español**, y en segundo lugar Inglés.
2. **Diseño Responsivo (Móvil)**: Hay que cuidar el formato móvil. Todas las interfaces deben ser 100% responsivas y verse bien en dispositivos móviles.
3. **HTML5 Semántico**: Hay que usar HTML5 en toda la página. Utilizar etiquetas semánticas (`<article>`, `<section>`, `<nav>`, `<header>`, `<footer>`, `<main>`, etc.) y **no usar `<divs>`**.
4. **Archivos CSS y JS Externos**: Todo el CSS debe ir en archivos `.css` dentro de la carpeta `Estilo`. Todo el JavaScript debe ir en archivos `.js` dentro de la carpeta `Scripts`. **No incluir código CSS o JS en línea en los archivos HTML.**
